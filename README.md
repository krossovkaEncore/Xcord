# Xcord — Децентрализованный мессенджер

Экспериментальный мессенджер на базе Reticulum Network Stack.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r core/requirements.txt
```

### Запуск сервера

```bash
cd core
python app.py
```

Сервер запустится на `http://localhost:8000`

### Запуск Jarvis (голосовой помощник)

```bash
cd core
python listener.py
```

## 📦 Структура проекта

```
xcord/
├── core/                    # Python backend
│   ├── app.py              # FastAPI сервер + Reticulum
│   ├── reticulum_backend.py # Reticulum/LXMF бэкенд
│   ├── Jarvis.py           # Голосовой помощник (упрощённый)
│   ├── listener.py         # Голосовой ввод
│   ├── config.py           # Конфигурация
│   └── requirements.txt    # Зависимости
├── index.html              # Frontend UI
├── styles/                 # CSS стили
├── scripts/                # JavaScript логика
│   ├── app.js              # Основная логика
│   ├── profile.js          # Профиль пользователя
│   ├── jarvis.js           # Jarvis UI
│   ├── reticulum-client.js # Reticulum API клиент
│   └── ...
├── assets/                 # Аватары и ресурсы
└── start_xcord.bat         # Скрипт запуска
```

## 🔧 Архитектура

### Frontend (JavaScript)
- Интерфейс мессенджера (HTML/CSS/JS)
- Профиль в стиле iOS 26 Glass
- Jarvis AI модальное окно
- Кастомизация темы
- Reticulum API клиент

### Backend (Python + FastAPI)
- REST API для frontend
- Интеграция с Reticulum/LXMF
- Обработка сообщений
- Jarvis AI команды

### Reticulum Network (P2P)
- Децентрализованная сеть
- LXMF — текстовые сообщения
- LXST — голосовые звонки (в разработке)
- Нет центральных серверов

### Jarvis AI (упрощённая версия)
- **gTTS** — быстрая озвучка (вместо CoTTS)
- Hugging Face API — LLM
- SpeechRecognition — голосовой ввод
- Генерация изображений (Stable Diffusion)

## 🔑 Ключевые особенности

### Децентрализация
- Нет серверов — клиенты общаются напрямую
- Сообщения хранятся при оффлайне получателя
- Graceful shutdown без потери данных

### Кастомизация
- Полная настройка интерфейса
- iOS 26 Glass стиль профилей
- Темы, цвета, анимации

### Jarvis AI (упрощённый)
- **gTTS** — быстрая озвучка (2-3 сек вместо 30+)
- Голосовые команды
- Текстовые команды в чате
- Генерация изображений
- Выполнение системных команд
